## 🚀 Featured Projects

- **[Finder](https://t.me/tryfinderbot)** - Telegram bot that finds freelance orders and jobs. It reads Telegram chats, Reddit, Hacker News, LinkedIn and niche forums, filters out ads, CVs and spam with LLMs, and sends each user the posts that fit their niches, budget and countries. Co-built at Nightloom (Python, SQLite, systemd, GitHub Actions).
- **[ISY](https://iseeyaai.com)** - code review for pull requests written by AI coding agents. The CLI reads the Claude Code, Codex or Kimi CLI session behind a PR, redacts secrets and paths before upload, and a GitHub App leaves one comment on the PR about how the work was done, not only the diff. Co-built at Nightloom: server, CLI, billing and deploys (TypeScript, Node.js, PostgreSQL/Prisma, Docker, Caddy). The CLI is open source: [ISY-cli](https://github.com/nightloom-dev/ISY-cli).
- **[Connect Anything](https://github.com/nightloom-dev/connect_anything)** - first place in the Aurora track at the Encode hackathon (November 2026). Paste a Solana program ID: it reads the Anchor IDL, builds a form for the instruction, simulates it on a mainnet fork and runs it from an EVM wallet with one signature. Next.js on Vercel.
- **[solar-relay](https://github.com/unwinned/solar-relay)** - Solana RPC resilience SDK for Node.js: health-based weighted routing, circuit breaker, priority fee estimation, Jito bundle routing, live CLI dashboard.
